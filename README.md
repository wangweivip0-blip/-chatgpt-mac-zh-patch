# ChatGPT macOS 离线中文工具

一键把 ChatGPT Mac 版界面切换为简体中文，无需联网，全程本地操作。

> 来源：抖音账号「是王不是黄」第 2 期视频《ChatGPT 一键汉化》的配套工具。

## 痛点

国内网络环境下，ChatGPT Mac 版的语言设置无法切换为简体中文。本工具通过本地补丁启用中文语言包，解决此问题。

## 使用方法（按编号顺序）

1. **先看** `先读我.md`，了解完整流程和注意事项
2. 完全退出 ChatGPT（Command-Q）
3. 双击 `1-检查是否支持.command`，确认你的版本支持
4. 双击 `2-原位修复中文.command`，按提示输入管理员密码，等待完成
5. 重新打开 ChatGPT，检查中文显示

需要还原时：
- `3-恢复原应用.command`：恢复应用本体
- `4-恢复原语言设置.command`：恢复语言设置

## 原理（一句话）

修改 App 内 asar 资源包的语言加载配置，启用内置中文语言文件，然后本地重新签名。所有操作均在本机完成，不联网。

## 注意事项

- 需要管理员密码（用于修改 /Applications 下的应用文件），工具不会记录密码
- 本地签名不具备 OpenAI 官方开发者身份，可能影响钥匙串、系统权限、消息通知和自动更新
- 运行前请完全退出 ChatGPT，运行过程不要强制结束
- 工具会自动备份原文件，备份保留在本机，可一键恢复
- 仅支持 macOS 版 ChatGPT 客户端
